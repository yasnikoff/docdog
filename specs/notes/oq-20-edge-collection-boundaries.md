# OQ-20: Edge collection boundaries — where does `companion` live?

**Resolved 2026-07-06 by DD-070** — the six edge collections collapse into a single edges table in the embedded cache; the boundary question dissolves by construction.

Five edge collections defined (structural, semantic, temporal, dependency,
crosscutting). The `companion` relationship (DD-ARCH-19 + DP-11 created together)
is about shared origin (temporal) but valued for semantic co-consideration.

Where it lives determines which traversal queries find it. Probably `temporal`
(it's about when/how they were created), with the semantic value derived by
agents who traverse temporal edges when exploring a decision's history.
