# OQ-29: Template naming — `--template orchestrator` is wrong

**Status:** RESOLVED — renamed to `structured`.

The template describes a documentation structure (decisions, requirements, principles,
guidelines, terms, domain, constraints, integrations, notes), not a project. Any project
with structured specs would use this template, not just the orchestrator.

Rename candidates considered: `structured`, `full`, `comprehensive`, `spec-driven`.
Picked `structured`. `minimal` (single `notes` collection) is fine as-is.
