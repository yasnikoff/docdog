# Relationship Extraction Is Agentic, Not Rule-Based

Cross-reference edges in the ArangoDB graph are extracted by an AI agent, not by
regex/pattern matching. Two modes:

1. **Initial population:** One large agentic pass over all existing specs. Burns tokens
   but produces a high-quality seed graph. Run once.
2. **Incremental:** On each index update (changed files), the agent extracts
   relationships from the changed chunks only. Low cost per update.

## Rationale

Cross-references in markdown are expressed in too many ways for rule-based extraction
("Related: DP-11", "see DD-ARCH-19", "per the principle in...", "as established in
refinement 0068"). An agent understands intent; regex catches syntax.
