# Agents Are Primary Content Creators; Description Is a Standard Frontmatter Field

Every vertex has a `description: string | null` field sourced from frontmatter. Agents
are advised to write or update `description:` on every create, update, or relate operation.

## Distinction From Preview

- `preview` — mechanical character slice of the body, word-boundary truncated. Always present.
  Agents do not write it.
- `description` — agent-authored summary of what the section covers. Null for files an
  agent has never touched. Preferred summary in search results; `preview` is the fallback.

## Indexer Behavior

Reads `description:` from frontmatter; stamps null if absent. Frontmatter edits
(including description) trigger metadata re-index but do not bust the embedding cache
(cache keyed to body hash, not file hash).

## Rationale

Agents produce better summaries than mechanical truncation. Making `description` a
first-class schema field encourages agents to treat it as a contract, exposes it as
an indexed field for audit queries, and provides a clear fallback chain for search results.
