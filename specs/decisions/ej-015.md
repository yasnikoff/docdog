# Embedding Cache Keyed by Content Hash

Embeddings are cached in a dedicated Arango collection keyed by content hash.
Eliminates re-embedding on branch switch and repeated indexing of unchanged content.

## Indexer Flow

1. Chunk file → compute content hash
2. Compare hash against current vertex in Arango — if unchanged, skip
3. If changed → look up `embedding_cache[content_hash]`
   - Cache hit → reuse embedding, no ONNX/Ollama call
   - Cache miss → generate embedding, store in cache, store in vertex
4. Vertex document carries both `content_hash` and `embedding` (copied from cache)

## Branch Switch Performance

Switching branches changes some sections' content. When switching back, the original
content hashes are still in the cache. Zero re-embedding. Branch switch cost = scan +
hash + cache lookups (all fast).

## Rationale

Solves the branch-switch ping-pong problem (same content re-embedded every switch)
without per-branch complexity. `content_hash → embedding` is a pure function —
caching it is always safe.
