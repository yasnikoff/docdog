# Cross-Platform, TypeScript Core, JS for Foxx Only

## Cross-Platform

Linux, Windows, macOS. Natural consequence of Node.js + Docker. No platform-specific
code, no native modules, forward-slash paths in Arango data.

## Language Split

- `src/` — TypeScript (indexer, MCP server, CLI, all core logic)
- `foxx/` — JavaScript (Foxx services deployed to ArangoDB — V8 requirement)
- `dist/` — compiled JS + generated d.ts (npm package output)

## Why TypeScript

- MCP tool API is a contract — typed parameters catch breaking changes at compile time
- Arango document schemas (VertexBase, EdgeBase) — without TS, every query result is `any`
- Multi-layer system (graph, embeddings, indexing, MCP) with multiple data shapes — TS's sweet spot
- d.ts generation is free with TS

## Rationale

TS prevents the class of bugs that matter most in docdog: silent schema drift between
layers, contract-breaking API changes, and stringly-typed cross-scope references. The
only JS is Foxx (required by ArangoDB) and optional ad-hoc scripts.
