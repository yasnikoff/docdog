# Accelerator-Mini Patching Stays As-Is

The patch system works well: keeps history, can be applied to new external versions,
incremental by default. Not changing the mechanism.

Long-term, patch specs could move into Foxx/ArangoDB — the database becomes the single
home for all project knowledge artifacts (refinements, patches, relationship graph,
indexes). But this is not a migration blocker.

## Rationale

Don't fix what works. The patch system is orthogonal to the exchange ceremony — it can
continue operating independently during and after migration.
