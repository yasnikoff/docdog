# Git-History-as-Archive for Extended Context

The Orchestrator worktree stays clean with summarizing documents. Extended context
(full conversations, agent-generated docs, requirement evolution) lives in git history —
committed then deleted from the worktree, same pattern already used for task folders.
Optional external source for supplementary context, but the Orchestrator must be
self-sufficient without it.

## Rationale

Pattern already proven in the Orchestrator's task workflow. Avoids repo bloat in the
worktree while preserving history for deep dives. External context is a bonus, not a
dependency.
