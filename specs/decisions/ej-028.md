# Ingest Split/Stamp as Core, Custom Formats as Project Scripts

Two generic ingest operations in docdog core:

## Split

`docdog ingest split <file> --on <pattern> --collection <name> --output <dir>`

Splits multi-section files on heading patterns. Extracts ID, title, Status, Date
into YAML frontmatter. Handles DD-*, DP-*, FR-*, EJ-*, CG-* ID formats.

## Stamp

`docdog ingest stamp <source> --collection <name> [--output <dir>]`

Adds/merges YAML frontmatter to existing individual files. Extracts title from
first heading, ID from filename pattern. Preserves existing frontmatter.

## Custom formats are scripts

The orchestrator's glossary (table-based, 92 terms) needs
`.docdog/scripts/ingest-glossary.ts`, not `docdog ingest glossary`.

## Rationale

A configurable general-purpose parser is hard to get right and maybe impossible.
Scripts are more powerful and require no upstream changes.
