# Docdog Lives at github.com/yasnikoff/docdog

Docdog is a standalone project, not embedded in docs-internal or the Orchestrator repo.
Repository: `github.com/yasnikoff/docdog`.

## Distribution

npm package published via GitHub Packages. Supports:
- `npx docdog init` — scaffold `.docdog/` in a project
- `npx docdog index` — index/re-index
- `npx docdog serve` — start MCP server
- Global install and npx-local both supported

## Dogfooding

docdog manages its own documentation. The project uses itself for context management
during development.

## Rationale

Docdog is a general-purpose tool, not tied to the Orchestrator. Own repo enables
independent versioning, releases, and contributions.
