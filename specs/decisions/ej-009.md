# Glossary Entries Are Individual Graph Vertices

Each glossary term becomes its own Arango document. Usage edges (`uses_term`,
`defined_by`) connect terms to the specs that reference them, providing a usage
index for free.

## What This Enables

- Agent encounters unfamiliar term -> definition + all specs that use it
- Agent writing a new spec -> "what does ResourcePlan mean?" -> definition + usage examples
- Progressive disclosure: start at the term, follow edges outward

## Maintenance Cost

Near-zero. Glossary has ~50-80 terms, each appearing in 5-20 specs. The edges are
created by the same agentic extraction pass as all other relationships (EJ-007). No
separate process.

## Rationale

Glossary entries are already self-contained definitions — natural graph vertices. The
usage index is a side effect of relationship extraction, not additional work. High value
for agent context discovery at trivial cost.
