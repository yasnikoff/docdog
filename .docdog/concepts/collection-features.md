# Collection: features

Feature matrix rows — each feature tracks a coherent slice of functionality with status, sub-layer, and linked tasks/requirements.

**When to use:** When a project needs a feature-level view that aggregates tasks and requirements.

## Status vocabulary

- `planned` — Scoped but not started.
- `in_progress` — Active tasks exist.
- `blocked` — Gated on a dependency or decision.
- `done` — All linked tasks complete.
- `deferred` — Deliberately pushed out of current scope.
