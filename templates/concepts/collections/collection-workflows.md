# Collection: workflows

Project process documents — release procedures, task loops, reconciliation flows. Agents read and follow them; docdog stores and serves.

**When to use:** When capturing a repeatable project process as a first-class, retrievable document rather than baking it into skill prose.

**When not to use:** For agent-how-to-use-docdog instructions — those are skills, not workflows.

## Status vocabulary

- `draft` — Being written, not yet followed.
- `current` — Active; agents may follow it.
- `deprecated` — Superseded; kept for history.
